# miz_maze
3D Maze Game for the Browser with Orbit View and FPV View

Language: German

## How to use:

Just start miz_maze_webgl_v13.html in the Browser on a PC. Controls are well known WSAD and rightclick the mouse to rotate the view / zoom with mousewheel.

If something is not working check what it is using miz_maze_diagnose.html

The Mobile Version (miz_maze_webgl_v20_mobile.html) is currently not local running on a smartphone, might be it requires a webserver with enabled javascript to make it work correctly.
