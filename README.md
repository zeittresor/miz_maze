# miz_maze
3D Maze Game for the Browser with Orbit View and FPV View

## How to use:

Just start miz_maze_webgl_v32.html in the Browser on a PC. Controls are well known WSAD and rightclick the mouse to rotate the view / zoom with mousewheel.
